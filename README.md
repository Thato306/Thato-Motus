# Mash Derby Supply ⚽

A dark-themed e-commerce web application built for football fans, featuring official replica home kits for Mamelodi Sundowns, Orlando Pirates, and Kaizer Chiefs.

## Features
* **Dark Sports Theme:** Pitch-black high-contrast UI with emerald green and gold accents.
* **Dynamic Search Bar:** Instantly filter kits by team name.
* **Interactive Modals:** Click "Quick View" to inspect kit specs, sizing, and material details.
* **Order Form Validation:** Built-in validation for customer orders and direct contact support.

## How to Run the Project Locally
1. Clone or download this repository to your local machine.
2. Open the project folder in **Visual Studio Code**.
3. Install the **Live Server** extension if you haven't already.
4. Right-click on `index.html` and select **"Open with Live Server"**.
